# Память экрана

Три инструмента:

- **screen_memory_start** — начать снимать экран в короткий буфер (по умолчанию
  кадр в секунду, хранится шестьдесят кадров).
- **screen_memory_stop** — остановить съёмку.
- **screen_memory_latest** — вернуть пути последних кадров, от новых к старым,
  чтобы агент посмотрел их сам.

Фоном не работает: съёмка идёт только пока её включили. Кадры складываются в
папку из настроек плагина (`framesDir`) и старые удаляются автоматически.
